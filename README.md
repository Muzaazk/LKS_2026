# 🏆 LKS Web Technology - Muzamil Zulkarnain Kubro

Repositori ini berisi rekam jejak perjalanan kompetisi, mulai dari kumpulan folder latihan, eksplorasi kode, hingga *source code* final project pada Lomba Kompetensi Siswa (LKS) SMK bidang **Web Technology**.

## 📂 Struktur Repositori

- **`/Latihan`**  
  Berisi *source code* persiapan lomba, uji coba logika PHP, eksplorasi desain, dan studi kasus (Speed Test) selama masa *training* di SMKN 1 Kebumen.
- **`/Hasil_LKS`**  
  Berisi project final yang diujikan pada saat pelaksanaan lomba secara resmi.

## 🚀 Pencapaian

- 🥇 **Juara 1** - LKS Web Technology Tingkat Kabupaten Kebumen
- 🏅 **Medallion for Excellence** - LKS Web Technology Tingkat Provinsi Jawa Tengah

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Tailwind/Bootstrap, React
- **Backend:** PHP (Native & Framework Laravel)
- **Database:** MySQL
- **Code Editor:** VS Code
